# NLP Internship Tasks – Cellula Technologies

This repository documents my weekly tasks from an **NLP internship at Cellula Technologies**. Each week focuses on a different area of modern NLP — from classic text classification and preprocessing pipelines, to **Transformer-based models**, **Large Language Models (LLMs)**, and **agentic AI systems**. Every task folder includes the data pipeline, model implementation, results, and a short write-up of what was built and learned.

## Topics Covered

- **Classic NLP** — text cleaning, preprocessing, tokenization, embeddings, and traditional sequence models (RNN/LSTM)
- **Transformers** — architecture internals, fine-tuning, and evaluation
- **LLMs** — prompting, evaluation, and applied use cases
- **Agentic AI** — tool use, multi-step reasoning, and agent workflows

## Structure

Each task is organized in its own folder with its data, code, and a short summary of the approach and results.
